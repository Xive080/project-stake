Herramientas para estudiar y portar a cualquier plataforma (Mac, Windows, Linux y Android) un arcade de pistola de PlayStation 2: Vampire Night, versión PAL SCES-50411. Dos líneas de trabajo: Decomp y Recomp.

Tools to study and port a PlayStation 2 light-gun arcade game, Vampire Night (PAL, SCES-50411), to any platform: Mac, Windows, Linux and Android. Two tracks: Decomp and Recomp.

En cursoIn progress

Decomp

Reconstruir el código fuente del juego y un motor nativo propio.

  • Compilador original identificado: Metrowerks CodeWarrior MIPS 2.4.1.01, -O4,p.
  • Herramientas para leer los contenedores AFS, mallas, texturas, esqueletos, movimientos, cámaras y colisiones.
  • Lógica de jugador, enemigos, jefes y escenas reescrita a mano con tests.
  • Visor nativo C++17 + SDL3 + OpenGL 3.3 que ya dibuja la primera fase con cielo, escenario y un enemigo posado.

Rebuild the game's source code and a native engine of our own.

  • Original compiler identified: Metrowerks CodeWarrior MIPS 2.4.1.01, -O4,p.
  • Tools to read the AFS containers, meshes, textures, skeletons, motions, cameras and collision data.
  • Player, enemy, boss and stage logic rewritten by hand, with tests.
  • Native viewer in C++17 + SDL3 + OpenGL 3.3 that already draws the first stage with sky, scenery and a posed enemy.
Por empezarNot started

Recomp

Traducir el código MIPS R5900 a C++ y enlazarlo con un runtime propio.

  • Primer experimento: traducir el ejecutable principal y llegar a main con un runtime mínimo.
  • Después: VU0/VU1, GIF/VIF/DMA y un GS sobre OpenGL/GLES, audio y entrada.
  • El código generado se produce en local, no se distribuye.

Translate the MIPS R5900 code to C++ and link it against a runtime of our own.

  • First experiment: translate the main executable and reach main with a minimal runtime.
  • Then: VU0/VU1, GIF/VIF/DMA and a GS on top of OpenGL/GLES, audio and input.
  • Generated code is produced locally and never distributed.

Cómo se complementan

How they fit together

El decomp documenta formatos, símbolos y comportamiento, y sirve de referencia para comprobar el resultado. La recompilación busca llegar antes a algo jugable reutilizando el código original. Lo aprendido en uno alimenta al otro.

The decomp documents formats, symbols and behaviour, and serves as the reference to check results against. Recompilation aims to reach something playable sooner by reusing the original code. What one learns feeds the other.

Método

Method

  • Se compara con el juego real ejecutado en un emulador, leyendo su memoria y comparando imágenes.
  • Todo lo que no está verificado contra el juego se marca como estimado.
  • Los tests de la lógica reescrita comprueban contra la lectura del ensamblador, no contra el juego completo.
  • Results are compared with the real game running in an emulator, reading its memory and comparing images.
  • Anything not verified against the game is marked as an estimate.
  • Tests of the rewritten logic check against our reading of the assembly, not against the full game.
