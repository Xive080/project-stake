Vampire Night Port

An unofficial fan project to decompile Vampire Night (PS2, PAL) and run it natively on Mac, Windows and Android. Not affiliated with Sega or Namco. No game files are included.

Recomp

The original program is translated to native code ahead of time and run on a small PS2 runtime. It starts, draws the Namco and WOW logos and reaches the “NOW LOADING” screen.

  • Threads, interrupts and the GS draw path work.
  • Loading runs slowly, about 45 of 60 frames per second.
  • Not playable yet.

Decomp

The code is rewritten by hand so that it compiles back to the same machine code as the original. A native viewer already shows stage 1 with sky, props and a posed enemy.

  • Compiler: CodeWarrior MIPS 2.4.1.01, -O4,p.
  • Tests compare against the assembly, not the running game.
